# CW exchange vocabulary
#
# Abbreviations, Q-codes and prosigns an operator sends verbatim. The decoder
# consults this list only to choose between readings that carry exactly the
# same characters, so an entry here can move a word boundary and can never
# change a decoded letter. Adding a token that is not real CW therefore costs
# accuracy in spacing, never correctness in text.
#
# One token per line. Blank lines and lines starting with '#' are ignored.
# Letters, digits and '/' only; case is not significant. Longer tokens carry
# more weight than short ones, because a single letter falls out of almost any
# spacing by chance while a three-character Q-code does not.
#
# Edit freely: this file is read at startup and never compiled in.
